# 🛡️ SurakshaText

### Regional-Language Phishing Detection & Awareness

SurakshaText is a web-based cybersecurity tool designed to help users identify potentially harmful phishing and scam messages in regional languages.

## 🎯 Problem

Phishing attacks increasingly target users through SMS, WhatsApp and email, including messages written in regional languages. Existing phishing detection tools are often English-centric, leaving many users underserved.

## 💡 Solution

SurakshaText allows users to:

- Paste suspicious messages
- Upload screenshots of suspicious messages
- Extract text using OCR
- Detect the message language
- Identify phishing indicators
- Classify messages as Safe, Suspicious or Dangerous
- Receive understandable explanations and safety recommendations

Input → OCR → Language Detection → Threat Analysis → Risk Score → Explanation
